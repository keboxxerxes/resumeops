# Scanner exceptions

Checkov 3.4.11 has fifteen resource-specific inline exceptions, each with a reason beside the affected resource. The independent [exception reassessment](EXCEPTION_REASSESSMENT.md) records one disposition per exact resource/check. These are explicit architecture tradeoffs or inapplicable feature checks, not proof that the associated security capabilities exist. No blanket skip is used.

| Resource | Checks | Rationale, actual controls and residual |
|---|---|---|
| Website and state S3 buckets | CKV_AWS_18 | S3 server-access log delivery to S3 is free; storing/accessing logs incurs ordinary storage/request charges. No log bucket is configured. Public-site visitor-data minimization and project scope support omission, but **state data-access auditing and object-request analysis are absent**. IAM, versioning and locks do not replace audit logs. |
| Website and state S3 buckets | CKV_AWS_144 | Single region with bounded version history. This can recover some object changes/deletions, but **is not regional disaster recovery**. A private operator state recovery backup is a prerequisite, not a verified existing backup. |
| Website and state S3 buckets | CKV_AWS_145 | SSE-S3 supplies at-rest encryption. There is no independent KMS key-policy authorization boundary. Customer-managed KMS key storage/request charges are excluded; **AWS-managed KMS key storage has no monthly charge**, though requests can incur charges. TLS and exact access policies address separate risks. |
| Website and state S3 buckets | CKV2_AWS_62 | No event consumer/backend or event-monitoring requirement is specified, so a blanket notification requirement is inapplicable. **Event-driven object/state-change notifications are absent**; native locks address concurrency, not monitoring. |
| Website CloudFront distribution | CKV_AWS_86 | No CDN visitor/access log collection. This minimizes visitor IP retention and log-storage overhead; **request-level analysis and auditing are unavailable**. HTTPS smoke tests validate sampled responses and metadata, not request history. |
| Website CloudFront distribution | CKV_AWS_310 | Intentional single origin. Version history/rollback can address content mistakes but do not supply origin failover; **origin/regional availability interruption remains possible**. |
| Website CloudFront distribution | CKV_AWS_374 | Resume intentionally globally reachable. Origin isolation remains, but no geography-based viewer restriction is claimed. |
| Website CloudFront distribution | CKV_AWS_68, CKV2_AWS_47 | Read-only assets without an application/Log4j runtime. Pay-as-you-go WAF base/rule charges conflict with the sub-USD 1 target. CloudFront's separate free flat-rate offering includes WAF, but **this Terraform distribution is not enrolled in it**. No WAF inspection or managed attack rules exist; CSP/origin controls do not replace them. |
| Website CloudFront distribution | CKV2_AWS_42 | Default CloudFront hostname/certificate is explicitly required. No custom domain/certificate lifecycle exists. |
| Website CloudFront distribution | CKV_AWS_174 | With the default CloudFront certificate AWS controls the minimum viewer TLS policy. **Legacy viewer TLS remains supported**; HTTPS redirect does not imply a TLS1.2 minimum. A custom policy requires the custom certificate/domain excluded by the current specification. A stricter requirement needs human-approved scope change. |

References: [CloudFront viewer certificate](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/DownloadDistValuesViewerCertificate.html), [provider viewer certificate](https://registry.terraform.io/providers/hashicorp/aws/6.74.0/docs/resources/cloudfront_distribution#viewer_certificate), [S3 encryption](https://docs.aws.amazon.com/AmazonS3/latest/userguide/default-bucket-encryption.html), [S3 logging](https://docs.aws.amazon.com/AmazonS3/latest/userguide/ServerLogs.html), [KMS pricing](https://aws.amazon.com/kms/pricing/), [WAF pricing](https://aws.amazon.com/waf/pricing/), [CloudFront pricing](https://aws.amazon.com/cloudfront/pricing/).

No suppression is allowed for public bucket access, missing encryption/versioning, insecure origin trust, wildcard OIDC subject, runtime IAM administration or unsafe credentialed workflows. Independent review found no additional resource necessary within the original specification, while retaining the residuals above as release-review information. Actual AWS policy, availability, recovery and delivery behavior remains unverified pending authorization.
